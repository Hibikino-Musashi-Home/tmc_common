開発関係者
----------
・竹下　佳佑

目的
----------
* stlファイルを読み込む

背景
----------
* 三角メッシュを干渉チェックで扱えるようにする

前提条件
----------
* バイナリフォーマットのstlファイル

振る舞い
----------
* ファイル名を元にstlファイルを読み込み、メッシュデータを返す

使用例
----------
### テスト

    $ roscd tmc_stl_loader
    $ make test

また、経過をディスプレイ表示したい場合は以下の通り。

    $ roscd tmc_stl_loader
    $ rosmake
    $ rostest test/stl_loader-test.test --text
